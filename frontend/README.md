# Braj Setu Properties Frontend

Premium real estate frontend for Braj Setu Properties, focused on verified buy, rent and sale listings across Vrindavan, Mathura, Govardhan, Barsana and nearby Braj Mandal locations.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The app uses TanStack Start, React, TypeScript, Tailwind CSS and Vite.
